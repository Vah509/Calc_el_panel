# HANDOFF

## Состояние

**v77 — у калькуляции появилась вкладка "Стоимость" — расчёт итоговой
цены изделия поверх суммы строк calculation_item (материалы +
комплекты), двумя способами на выбор.**

Формула (согласована с Вахтангом 2026-08-26):
1. `materials_total` = Σ строк с `material_id`, `kits_total` = Σ строк
   с `kit_id` (обе снэпшоты, как и цены самих calculation_item)
2. `base_total` = materials_total + kits_total
3. `insured_total` = base_total × `insurance_markup` (страховочная
   наценка, дефолт 1.1 из константы `insurance_markup`, редактируется
   вручную на самой калькуляции)
4. Способ "Наценка": `markup_total` = insured_total × `markup_percent`
   (дефолт 1.4 из константы `markup_percent`, тоже редактируется
   вручную на калькуляции)
5. Способ "По часам": `hours_total` = insured_total + `assembly_hours`
   × стоимость часа выбранного `product_type_rate_id` (новый
   справочник "Стоимость сборки" — тип изделия + стоимость часа,
   т.к. сложные и простые изделия могут иметь разную стоимость часа)
6. `final_total` = markup_total либо hours_total, в зависимости от
   `cost_method` (radio-переключатель "markup"/"hours")

Оба блока (наценка и часы) видны на форме ОДНОВРЕМЕННО — переключатель
влияет только на то, какая сумма попадает в `final_total`, не на
видимость полей. Если у калькуляции ещё нет ни одной строки — всё
считается как 0 без ошибки (пустой список сумма 0 — не invalid state).

Пересчёт — той же кнопкой "Пересчитать", что уже пересчитывала цены
материалов на вкладке "Материалы" (`recalc_material_prices`): сначала
обновляются цены строк calculation_item, затем на их основе
пересчитывается вся вкладка "Стоимость" (`_recalc_cost_totals`).
Сохраняется обычной кнопкой "Сохранить" формы.
