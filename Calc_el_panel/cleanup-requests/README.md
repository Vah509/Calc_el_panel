# cleanup-requests/

Сюда кладутся `.txt`-файлы со списком путей на удаление из
репозитория — отдельно от `ai-updates/` (там только архивы кода).

## Как это работает

1. Claude кладёт в эту папку файл вида `cleanup_2026-08-12.txt` со
   списком путей — по одному на строку, относительно корня
   репозитория. Файлы и директории — можно вперемешку.
2. Файл заливается в GitHub через браузер (как обычно).
3. Вахтанг заходит в GitHub → **Actions** → workflow
   **"Repo Cleanup (manual)"** → нажимает **"Run workflow"** вручную.
4. Скрипт `scripts/process_cleanup.py` удаляет перечисленные пути,
   коммитит изменения и присылает отчёт в Telegram — что именно
   удалено.

Обработанный `.txt`-файл скрипт удаляет сам после запуска — чтобы
повторный запуск того же workflow не сработал вхолостую.

## Важно

- Запуск **только вручную** — по push в эту папку ничего не
  происходит автоматически. Это намеренно, для гарантии: заливка
  списка сама по себе ничего не удаляет.
- Пустые строки и строки, начинающиеся с `#`, в файле списка
  игнорируются — можно оставлять комментарии.
- Если путь в списке уже не существует — это не ошибка, просто
  отмечается в отчёте как "уже отсутствует".

## Пример содержимого файла списка

```
# Устаревшие HTMX-шаблоны после перехода на Alpine
app/templates/materials/_form.html
app/templates/materials/_row.html
app/templates/materials/_tbody.html
```
