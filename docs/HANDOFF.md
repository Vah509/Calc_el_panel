## Сделано в этой сессии

1. **`docs/HANDOFF_kits_and_calculation.md` — удалён целиком.** Это
   был дневник проектирования этапа calculation/specification/invoice,
   который уже полностью закодирован и в проде (v91–v94). Актуальные
   архитектурные решения оттуда перенесены в `entity_registry.md`
   (раздел "Документооборот"), исторические черновики решений — не
   переносились, при необходимости доступны в git-истории файла.
2. **`entity_registry.md` — полностью переписан** (был v48 → теперь
   v94-актуальный). Новый формат: инфраструктура/движок/документооборот/
   печатные формы одним блоком в начале, затем ВСЕ 19 таблиц проекта
   (было заметно меньше в v48 — не было request/calculation/
   calculation_item/specification/specification_item/firm/invoice/
   invoice_item вообще) в порядке `ALL_TABLES`, в конце — таблица
   известных расхождений код/спека и технического долга. Это теперь
   основной документ, на который можно опираться при вопросах "что и
   как устроено сейчас" — не история решений (та в HANDOFF.md/git), а
   срез по факту кода.
3. **`app/engine/ENGINE.md` — полностью переписан** (был v25 → теперь
   v94-актуальный). Раньше описывал только `/material-v2`/`/brand-v2`;
   теперь покрывает все примитивы, добавленные с тех пор: `Hierarchy`
   (и чем отличается от `document_chain.py`), три построчных примитива
   (`materials_tab`/`readonly_items_tab`/`invoice_items_tab`) и когда
   какой выбирать, `form_tabs`, `ActionButton`+хуки
   (`before_create_hook`/`before_update_hook`/`open_edit_action`),
   нумерация документов, `_ensure_is_deleted_columns` как отдельный
   критичный пункт при добавлении полей на уже задеплоенные таблицы.
4. **`README.md` — переписан** под реальный стек. Было: название
   "Pricing App", упоминания `app/routers/` (давно нет — всё через
   движок), WeasyPrint + Tesseract OCR в описании (давно заменены).
   Стало: реальное название, реальная структура (`engine/`,
   `documents_chain/`, `invoice_print/`, `processors/`), reportlab +
   openpyxl, ссылки на `entity_registry.md`/`ENGINE.md` как источники
   подробностей вместо дублирования содержимого в README.
5. **`Dockerfile` — убраны системные библиотеки Pango/Cairo/GDK-pixbuf/
   Tesseract** (были нужны для WeasyPrint + Tesseract OCR, которых в
   проекте больше нет — `requirements.txt` подтверждённо не содержит
   пакетов, требующих их). Только по прямому запросу Вахтанга при
   обсуждении README (не входило в исходную задачу "документация", но
   решено сделать в этой же сессии). Эффект — быстрее сборка образа и
   меньше итоговый размер на Railway.
6. **`cleanup-requests/README.md`** — НЕ трогали, он актуален и
   рабочий.
7. Проверено: `TestClient` + `/health` → 200 после всех правок —
   приложение по-прежнему собирается и запускается (документация и
   Dockerfile изменений в Python-код не вносили, но regression-check
   сделан).
