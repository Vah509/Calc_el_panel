# Changelog — elektroschit.com.ua

Человекочитаемая хронология ключевых изменений сайта. Не заменяет git log —
это краткая сводка "что и когда", чтобы не искать по коммитам, когда нужно
вспомнить, в какой момент что-то было сделано или почему.

Формат: дата — что изменилось.

---

## 2026-09-26
- Полная ревизия документации `docs/site/` по реальному коду репозитория
  (не по памяти/старым заметкам):
  - `context.md` дополнен: полное описание `/ru/` (маппинг UA↔RU slugs,
    поля `page.lang`/`page.altUrl`, заглушка `/ru/vykonani-roboty/`),
    полная таксономия `tags-registry.ts` (10 types, 3 tags, 8 properties —
    было задокументировано только 2 tags и 4 properties), точные пропсы
    Work-компонентов (`WorkDescription` принимает `properties`, `WorkSimilar`
    принимает `relatedTop`/`moreWorks`/`currentTypeLabel`, а не
    `currentSlug`/`types`/`tags` как считалось ранее), алгоритм
    `similarWorksGraph.ts` (двухфазный граф с защитой от карточек-сирот,
    а не «топ-3 по дате», как было в старой версии)
  - **Исправлена ошибка:** фото-пайплайн деплоя работает на Node.js +
    `sharp` (`scripts/lib/optimize-photos.js`), а не на Python/Pillow, как
    ошибочно указывалось раньше. Качество сжатия — 85, не 82
  - `deploy-and-sitemap.md` дополнен полным разбором всех модулей
    `scripts/lib/` (`lastmod.js`, `staging.js`, `read-archive.js`,
    `test-build.js`, `send-telegram.js`) и точной механикой расчёта
    `lastmod-map.json`

## 2026-09-25
- Реорганизована структура документации в `docs/`: разделена на `site/`
  (техническая документация о сайте) и `marketing/` (продвижение, теги,
  аналитика). См. `docs/README.md` для полного оглавления.
- Обнаружена и задокументирована проблема: тег `GA4 — click_cta_hero`
  отправляет название события с лишним префиксом (`GA4 — click_cta_hero`
  вместо `click_cta_hero`) — требует исправления в GTM.
- Просмотрены первые реальные данные GA4 за две недели (18–24 сент.):
  подтверждена работа `view_portfolio_item`, `click_cta_header`,
  `click_also_make`. Конверсионные события (телефон, email, мессенджеры)
  пока не сработали — трафика ещё немного, преждевременно делать выводы.

## 2026-09-06
- Настроены события кликов и просмотров в GTM → GA4 (12 тегов, 12 триггеров):
  клики по телефону/Viber/Telegram/WhatsApp/email/карте, просмотр карточки
  портфолио, открытие FAQ, клик по "Также изготавливаем", открытие лайтбокса
  галереи, клики по CTA-кнопкам (шапка и hero).
- Обнаружено и исправлено: email-ссылка на сайте отдаётся Cloudflare
  непоследовательно (то `mailto:`, то обфусцированный `cdn-cgi/l/email-protection`)
  — добавлены два триггера на оба варианта.
- Обнаружено и исправлено: CSS-селекторы для FAQ/галереи/"Также изготавливаем"
  не ловили клики по вложенным элементам (иконкам, картинкам) — селекторы
  расширены на дочерние элементы.
- Создана папка `docs/` в репозитории для технической документации проекта.

## 2026-07-31
- Убран `git log` из `sitemap.xml.ts` (падал на Cloudflare Pages из-за
  shallow clone). Даты теперь считаются один раз в GitHub Actions и
  сохраняются в `src/data/lastmod-map.json`.

## 2026-07-19

## 2026-07-12
