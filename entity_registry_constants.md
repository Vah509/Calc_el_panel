# Реестр сущностей — constants (v26)

## Таблица `constant`

| Поле | Тип | Назначение |
|---|---|---|
| id | int, PK | |
| key | str, unique, indexed | Ключ константы (`vat_rate`, `default_page_size`). Readonly в UI и API — меняется только через seed. |
| value | str | Значение. Хранится строкой, тип приводится в коде в месте использования. |
| description | str | Пояснение для человека, что это за константа (readonly, только в списке). |

Стартовые записи (`seed_constants()`, `app/database.py`, вызывается в `on_startup`):
- `vat_rate = "20"` — ставка НДС (%)
- `default_page_size = "100"` — лимит строк в списках

Seed идемпотентен — не создаёт дубликаты и не перезаписывает изменённые значения при повторном старте.

## Изменения движка (app/engine/config.py, api.py, page.py)

| Что добавлено | Где | Поведение |
|---|---|---|
| `FieldConfig.readonly` | config.py | Поле — текст в форме, не input. `update_item` в api.py игнорирует readonly-поля в payload. |
| `TableConfig.allow_create` | config.py | `False` → кнопка "+ Добавить" скрыта, POST возвращает 422. |
| `TableConfig.allow_delete` | config.py | `False` → кнопка "Удалить" скрыта, DELETE возвращает 422. |

Все три флага — общие для движка, не специфичны для constants; доступны любой будущей таблице.

## Страница

`/constant-v2` — список + модалка редактирования (только поле `value`). Кнопки создания/удаления не показываются (allow_create/allow_delete = False).

## Известные расхождения / решения

Ничего не расходится со спекой на этом шаге — движок расширен строго под непосредственную потребность (readonly + allow_create/allow_delete), без опережающего функционала (пагинация как таковая не реализована — `default_page_size` пока просто лежит в справочнике, применение — отдельная будущая задача, не поднимать без запроса).
