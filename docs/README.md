# Документация — elektroschit.com.ua

Техническая и маркетинговая документация проекта. Обновляется вручную по
мере изменений — не автогенерируется. См. `changelog.md` для хронологии.

---

## Структура

### `site/` — как устроен сайт технически
- **[context.md](site/context.md)** — главный техпаспорт: архитектура,
  стек, структура страниц (включая `/ru/`), компоненты (включая
  Work-компоненты и алгоритм «Схожих работ»), конфигурация (`config.ts`),
  полная таксономия продуктов (`tags-registry.ts`), схема коллекции
  портфолио, slugs продуктов, правила доставки изменений (ZIP), реальный
  фото-пайплайн
- **[layouts.md](site/layouts.md)** — подробная документация по
  `BaseLayout.astro` и `ProductLayout.astro`: все пропсы, примеры
  использования, справочник значений `section`
- **[deploy-and-sitemap.md](site/deploy-and-sitemap.md)** — как работает
  автоматический деплой через `process-update.js` (все модули
  `scripts/lib/`, пошагово, включая расчёт `lastmod-map.json`) и почему
  sitemap.xml не использует `git log` напрямую

### `marketing/` — продвижение и аналитика
- **[gtm-ga4-tags.md](marketing/gtm-ga4-tags.md)** — полный список
  событий GTM/GA4, что каждое отслеживает, известные технические нюансы
  и проблемы, снимки реальных данных

*(в этом разделе со временем появятся заметки по SEO, Google Ads и
другим маркетинговым темам, когда до них дойдёт очередь)*

### В корне
- **[changelog.md](changelog.md)** — хронология ключевых изменений
  по всему проекту (не только код — включая настройки аналитики,
  структурные решения и т.д.)
