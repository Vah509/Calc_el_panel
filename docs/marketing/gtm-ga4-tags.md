## ⚠️ Известная проблема: название события `click_cta_hero`

**Обнаружено:** 2026-09-25, при первом просмотре реальных данных за две недели.

В стандартном отчёте GA4 "Reports snapshot" событие отображается как
**`GA4 — click_cta_hero`** — то есть с префиксом `GA4 —`, который на самом
деле является **названием тега**, а не названием события. Похоже, при
создании тега в поле "Название события" было по ошибке скопировано имя
самого тега вместо чистого `click_cta_hero`.

**Как исправить:**
1. GTM → Теги → открыть `GA4 — click_cta_hero`
2. Проверить поле **"Название события"** — если там указано
   `GA4 — click_cta_hero` (с префиксом), заменить на просто `click_cta_hero`
3. Сохранить, проверить через Preview, опубликовать

**Пока не исправлено** — сравнивай данные по этому событию именно под
именем `GA4 — click_cta_hero` в отчётах GA4, а не под `click_cta_hero`.

## Технические нюансы (важно при отладке)

### Email — два триггера на одно событие
Cloudflare Scrape Shield обфусцирует email-ссылку непоследовательно:
иногда `Click URL` = `mailto:elektroschit.info@gmail.com`, иногда —
`/cdn-cgi/l/email-protection#...`. Причина расхождения не выяснена
(возможно, разные версии кэша Cloudflare). Тег `GA4 — click_email`
привязан сразу к двум триггерам (`Click — Email` и `Click — Email
(mailto)`), чтобы событие срабатывало при любом варианте URL.

### FAQ, галерея, "Также изготавливаем" — расширенные CSS-селекторы
Изначальные селекторы (`.em-faq-question`, `.em-gallery-item`,
`.em-product-card`) не ловили клики по вложенным элементам — иконке "+"
в FAQ, картинке `<img>` внутри карточки галереи, тексту внутри карточки
товара. Все три триггера используют расширенный селектор вида:
```
.em-faq-question, .em-faq-question *
```
(звёздочка означает "любой потомок этого элемента").

### `click_cta_hero` считает две разные кнопки вместе
Класс `.em-btn-primary` используется и на кнопке "Замовити / Зв'язатися
з нами" в hero-блоке, и на кнопке "Переглянути роботи →" в блоке галереи
продуктовых страниц. Событие `click_cta_hero` фиксирует клики по обеим —
это сознательно принятое упрощение. Различить их в будущем можно будет
только через правку кода сайта (уникальный класс на одной из кнопок).

### `click_cta_header` — уникальный класс, проблем нет
Кнопка "Залишити заявку" в шапке имеет уникальный класс `.em-header-cta`,
не встречающийся больше нигде на сайте — событие считает точно её.
