# Pricing App — автоматизация ценообразования электрощитов

Стартовый каркас проекта. Деплой полностью через Railway (автодеплой
по пушу в `main`).

## Структура

- `main.py` — точка входа FastAPI-приложения
- `requirements.txt` — Python-зависимости
- `Dockerfile` — сборка образа, включает системные библиотеки для
  WeasyPrint (генерация PDF) и Tesseract OCR (распознавание счетов)

## Проверка после деплоя

Открыть `/` — должна показаться страница с подтверждением, что
приложение живо и видит (или не видит) переменную `DATABASE_URL`.

Открыть `/health` — должен вернуться `{"status": "ok"}`.
